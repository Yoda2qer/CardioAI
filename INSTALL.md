# CardioAI: установка и запуск

Это руководство описывает, как установить платформу курса «CardioAI: Аналитика данных и машинное обучение» на компьютер или сервер, запустить её, создать администратора и открыть доступ слушателям. Опыт программирования не требуется: все команды приведены полностью.

## 1. Что понадобится

| | Требование |
|---|---|
| Операционная система | Windows 10 или 11, macOS 12 и новее, Linux |
| Python | версия 3.11, 3.12 или 3.13 (платформа проверена на 3.13) |
| Место на диске | около 300 МБ, с офлайн-режимом — около 400 МБ |
| Браузер у слушателей | свежий Chrome, Edge, Firefox или Safari |
| Интернет | для установки; у слушателей — для первой загрузки среды Python в практических уроках (без интернета — см. раздел 9) |

Платформа состоит из сервера, который хранит учётные записи и прогресс, и сайта, который открывают слушатели. Код практических заданий выполняется не на сервере, а в браузере слушателя, поэтому мощный сервер не нужен: для группы в несколько десятков человек достаточно обычного рабочего компьютера.

## 2. Установка Python

Проверьте, не установлен ли Python уже. Откройте терминал (в Windows — «Командная строка» или PowerShell, в macOS — «Терминал») и выполните:

```bash
python --version
```

Если в ответ напечатано `Python 3.11` или новее, переходите к разделу 3. Иначе установите Python.

### Windows

**Способ 1.** Скачайте установщик с [python.org/downloads](https://www.python.org/downloads/) и запустите его. На первом экране **обязательно отметьте пункт «Add python.exe to PATH»**, затем нажмите «Install Now».

**Способ 2.** В PowerShell выполните:

```powershell
winget install --id Python.Python.3.13 -e
```

После установки закройте и снова откройте терминал, чтобы он «увидел» Python.

> [!NOTE]
> **Если команда `python` открывает Microsoft Store.** В Windows вместо Python может запускаться заглушка магазина приложений. Установите Python одним из способов выше и отключите заглушку: «Параметры» → «Приложения» → «Дополнительные параметры приложений» → «Псевдонимы выполнения приложений» → выключите `python.exe` и `python3.exe`.

### macOS

Установите Python с [python.org/downloads](https://www.python.org/downloads/) или через Homebrew:

```bash
brew install python@3.13
```

### Linux (Debian, Ubuntu)

```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip
```

## 3. Получение файлов платформы

**Через Git** (если он установлен):

```bash
git clone https://github.com/Toster1012/CardioAI.git
cd CardioAI
```

**Без Git.** Откройте [github.com/Toster1012/CardioAI](https://github.com/Toster1012/CardioAI), нажмите «Code» → «Download ZIP», распакуйте архив и перейдите в получившуюся папку.

## 4. Быстрый запуск

В папке платформы есть скрипты, которые выполняют все шаги установки сами.

**Windows:** дважды щёлкните файл `run.bat` или выполните в терминале (PowerShell или командной строке) из папки платформы:

```powershell
.\run.bat
```

**macOS и Linux:**

```bash
chmod +x run.sh
./run.sh
```

При первом запуске скрипт:

1. создаёт виртуальное окружение `.venv` — отдельную копию Python для платформы, не затрагивающую остальную систему;
2. устанавливает библиотеки из `requirements.txt` (нужен интернет, 1–3 минуты);
3. создаёт базу данных `instance/cardioai.db`;
4. просит ввести email, ФИО и пароль **администратора** (символы пароля при вводе не отображаются — так и задумано);
5. создаёт первый **код приглашения** и печатает его — сохраните этот код;
6. запускает сервер.

Когда в окне появится строка `Uvicorn running on http://127.0.0.1:8000`, откройте в браузере адрес **http://localhost:8000** (если порт меняли параметром `--port`, номер будет другим). Окно терминала не закрывайте: пока оно открыто, сайт работает. Остановить сервер — сочетание клавиш `Ctrl+C`.

Повторные запуски выполняются тем же скриптом и занимают несколько секунд: установка и создание администратора пропускаются.

## 5. Ручной запуск по шагам

Если скрипт не подходит или вы хотите понимать каждый шаг, выполните команды вручную из папки платформы.

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe manage.py init-db
.venv\Scripts\python.exe manage.py create-admin
.venv\Scripts\python.exe manage.py create-invite
.venv\Scripts\python.exe manage.py run
```

**macOS и Linux:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py init-db
.venv/bin/python manage.py create-admin
.venv/bin/python manage.py create-invite
.venv/bin/python manage.py run
```

Служебные команды `manage.py`:

| Команда | Что делает |
|---|---|
| `init-db` | создаёт таблицы базы данных (повторный вызов безопасен) |
| `create-admin` | создаёт администратора; для существующего пользователя — делает его администратором, а с параметром `--password` ещё и задаёт новый пароль |
| `create-invite` | создаёт код приглашения; параметры `--code`, `--note`, `--max-uses` |
| `has-admin` | проверяет, есть ли администратор (используется скриптами запуска) |
| `run` | запускает сервер; параметры `--host`, `--port` |

Справка по любой команде: `manage.py run --help`.

## 6. Первый вход и приглашение слушателей

1. Откройте http://localhost:8000 и нажмите «Войти». Используйте email и пароль администратора.
2. В шапке появится пункт **«Слушатели»** — это панель администратора.
3. На вкладке **«Коды приглашения»** создайте код для группы. Можно задать подпись («Ординаторы, поток 2026») и лимит регистраций.
4. Передайте слушателям адрес сайта и код. Они регистрируются сами, указывая ФИО — оно будет напечатано в сертификате.

Что видит администратор:

- список слушателей с прогрессом и результатами тестов;
- карточку слушателя: даты прохождения уроков, попытки тестов, код практических заданий;
- кнопки «Выдать временный пароль», «Сбросить попытки» теста, «Заблокировать», «Сделать администратором».

Администратору открыты все уроки без соблюдения порядка — это удобно для подготовки занятий. Слушатели проходят курс строго по порядку: тест раздела открывается после всех его уроков, следующий раздел — после сдачи теста на 80% и выше. На тест даётся три попытки, затем пауза 24 часа; администратор может сбросить попытки досрочно.

## 7. Настройки

Настройки задаются в файле `.env` в папке платформы. Создайте его из образца:

```bash
cp .env.example .env
```

В Windows: `copy .env.example .env`. Затем откройте `.env` в любом текстовом редакторе. После изменения настроек перезапустите сервер.

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `SECRET_KEY` | создаётся автоматически | ключ подписи сессий; на сервере задайте вручную |
| `DATABASE_URL` | `sqlite:///instance/cardioai.db` | база данных |
| `BASE_URL` | `http://localhost:8000` | адрес сайта для ссылок в письмах и сертификатах |
| `COOKIE_SECURE` | `false` | `true`, если сайт работает по HTTPS |
| `REGISTRATION_MODE` | `invite` | `invite` — регистрация по коду, `open` — свободная |
| `PYODIDE_BASE_URL` | CDN jsDelivr | откуда браузер загружает Python (раздел 9) |
| `QUIZ_PASS_PERCENT` | `80` | проходной балл теста, % |
| `QUIZ_MAX_ATTEMPTS` | `3` | попыток в одной серии |
| `QUIZ_COOLDOWN_HOURS` | `24` | пауза после исчерпания попыток, часов |
| `MAIL_BACKEND`, `SMTP_*` | отключено | почта для сброса паролей (раздел 10) |

## 8. Доступ с других компьютеров сети

По умолчанию сайт доступен только на том компьютере, где запущен сервер. Чтобы его открывали коллеги в локальной сети:

1. Запустите сервер с параметром `--host 0.0.0.0`:

   ```powershell
   .\run.bat --host 0.0.0.0
   ```

   (в macOS и Linux — `./run.sh --host 0.0.0.0`).

2. Узнайте IP-адрес компьютера: в Windows — команда `ipconfig` (строка «IPv4-адрес»), в macOS и Linux — `ip addr` или «Системные настройки» → «Сеть».
3. Слушатели открывают `http://IP-адрес:8000`, например `http://192.168.1.25:8000`.
4. Если сайт не открывается, разрешите входящие подключения к Python на порт 8000 в брандмауэре. В Windows при первом запуске система обычно сама предлагает это сделать — выберите «Частные сети».
5. Укажите этот адрес в `.env`: `BASE_URL=http://192.168.1.25:8000`.

> [!WARNING]
> **Безопасность.** Запуск с `--host 0.0.0.0` открывает сайт для всей сети, к которой подключён компьютер. Делайте это только в доверенной сети учреждения. Для доступа из интернета используйте схему из раздела 13 с HTTPS.

## 9. Работа без интернета

Практические задания выполняются средой Python, которая загружается в браузер слушателя (Pyodide, около 55 МБ). По умолчанию она берётся с публичного CDN, поэтому слушателю нужен интернет; браузер кэширует загруженное, и повторные открытия проходят быстро.

Если в сети учреждения нет доступа в интернет, скачайте среду на сервер один раз (на компьютере с интернетом):

```bash
.venv/bin/python scripts/fetch_pyodide.py
```

В Windows: `.venv\Scripts\python.exe scripts\fetch_pyodide.py`. Скрипт загрузит Pyodide и только те библиотеки, которые нужны курсу, сверит контрольные суммы и сохранит файлы в `app/static/vendor/pyodide/`. Затем добавьте в `.env` строку

```
PYODIDE_BASE_URL=/static/vendor/pyodide/
```

и перезапустите сервер. Теперь всё, что нужно слушателям, раздаёт сам сервер.

## 10. Почта для сброса паролей

Без настроенной почты страница «Забыли пароль?» предлагает обратиться к администратору, а администратор выдаёт временный пароль кнопкой в карточке слушателя. Этого достаточно для работы.

Чтобы слушатели могли сбрасывать пароль сами, укажите в `.env` параметры почтового сервера вашей организации:

```
SMTP_HOST=smtp.example.ru
SMTP_PORT=587
SMTP_USER=cardioai@example.ru
SMTP_PASSWORD=пароль-почтового-ящика
SMTP_FROM=CardioAI <cardioai@example.ru>
SMTP_STARTTLS=true
BASE_URL=http://адрес-вашего-сайта:8000
```

Ссылка из письма действует один час и перестаёт работать после смены пароля. Для проверки без реальной почты задайте `MAIL_BACKEND=console` — письма будут печататься в окне сервера.

## 11. Резервное копирование

Все данные платформы — учётные записи, прогресс, результаты тестов, сертификаты — хранятся в папке `instance/`:

- `instance/cardioai.db` — база данных;
- `instance/secret_key` — ключ сессий (если `SECRET_KEY` не задан в `.env`).

Чтобы сделать резервную копию, остановите сервер (`Ctrl+C`) и скопируйте папку `instance` в надёжное место. Для восстановления верните её на место. Делайте копию перед каждым обновлением и регулярно во время курса.

## 12. Обновление

1. Остановите сервер и сделайте резервную копию (раздел 11).
2. Получите новую версию: `git pull` или скачайте ZIP заново и перенесите в новую папку свои `instance/` и `.env`.
3. Запустите `run.bat` или `run.sh` — скрипт сам установит изменившиеся зависимости.

## 13. Размещение на сервере

Для доступа из интернета платформу размещают на сервере (VPS или облачная площадка) за обратным прокси с HTTPS.

### Docker

```bash
docker build -t cardioai .
docker volume create cardioai-data
docker run -d --name cardioai -p 127.0.0.1:8000:8000 \
  -v cardioai-data:/srv/cardioai/instance \
  -e SECRET_KEY="длинная-случайная-строка" \
  -e BASE_URL="https://cardioai.example.ru" \
  -e COOKIE_SECURE=true \
  cardioai
docker exec -it cardioai python manage.py create-admin
docker exec -it cardioai python manage.py create-invite
```

Том `cardioai-data` хранит базу между обновлениями образа. Случайную строку для `SECRET_KEY` можно получить командой `python -c "import secrets; print(secrets.token_urlsafe(48))"`.

### Обратный прокси с HTTPS

Пример для nginx (сертификат можно получить бесплатно через Let's Encrypt):

```nginx
server {
    listen 443 ssl;
    server_name cardioai.example.ru;
    ssl_certificate     /etc/letsencrypt/live/cardioai.example.ru/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/cardioai.example.ru/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### Без Docker

На сервере выполните шаги раздела 5 и запустите сервер как системную службу (systemd в Linux) командой `manage.py run --host 127.0.0.1 --port 8000`, поставив перед ним обратный прокси.

### PostgreSQL

SQLite достаточно для групп в десятки и сотни слушателей. Если площадка предоставляет PostgreSQL, установите драйвер и укажите адрес базы:

```bash
.venv/bin/python -m pip install "psycopg[binary]"
```

```
DATABASE_URL=postgresql+psycopg://пользователь:пароль@сервер:5432/cardioai
```

Таблицы создаются автоматически при запуске.

### Чек-лист перед открытием доступа

- задан собственный `SECRET_KEY`;
- сайт работает по HTTPS, `COOKIE_SECURE=true`, `BASE_URL` начинается с `https://`;
- регистрация только по кодам приглашения (`REGISTRATION_MODE=invite`);
- настроено регулярное резервное копирование тома или базы.

## 14. Для разработчиков курса

Содержимое курса хранится в папке `content/` и не требует программирования для правки текста.

| Файл | Что в нём |
|---|---|
| `content/course.yaml` | разделы и порядок уроков |
| `content/section-N/*.md` | теоретические уроки в формате Markdown |
| `content/section-N/*-practice-*.yaml` | практические задания: условие, заготовка кода, эталонное решение и проверки |
| `content/section-N/quiz.yaml` | 15 вопросов теста с пояснениями |

В уроках поддерживаются врезки `::: clinic`, `::: note`, `::: warning`, `::: summary`. Код после блока ` ```python ` выполняется, а его вывод подставляется в блок ` ```output ` командой:

```bash
.venv/bin/python scripts/sync_lesson_outputs.py
```

Так все числа и графики в уроках получаются тем же кодом, который видит слушатель. Для разработки установите дополнительные библиотеки и запускайте тесты:

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

Тесты проверяют работу платформы, структуру курса, эталонные решения всех практических заданий и актуальность вывода в уроках. Значения для поля `expected` в новом задании подскажет `scripts/run_solution.py путь/к/заданию.yaml`. После правки содержимого перезапустите сервер: курс читается при старте, а ошибка в файлах остановит запуск с сообщением, где именно она находится.

Эта инструкция в формате PDF собирается командой `python scripts/build_manual_pdf.py` (нужен установленный Chrome или Edge).

## 15. Типичные ошибки

| Симптом | Причина и решение |
|---|---|
| `python` не найден или открывается Microsoft Store | Python не установлен или не добавлен в PATH — раздел 2 |
| `No module named venv` (Linux) | установите пакет `python3-venv` |
| `address already in use`, порт 8000 занят | сервер уже запущен в другом окне, или порт занят другой программой — запустите с `--port 8080` |
| На странице практики «Среда Python не загрузилась» | у слушателя нет доступа к CDN — проверьте интернет или включите офлайн-режим (раздел 9); убедитесь, что браузер свежий |
| Первый запуск кода в практике идёт долго | при первом открытии браузер загружает около 55 МБ; дальше они берутся из кэша |
| «Сессия устарела. Обновите страницу» | форма была открыта слишком долго или в другой вкладке выполнен вход/выход — обновите страницу |
| Слушатель забыл пароль | администратор: «Слушатели» → карточка → «Выдать временный пароль» |
| Администратор забыл пароль | `manage.py create-admin --email адрес --password новый-пароль` |
| Слушатель исчерпал попытки теста | администратор: карточка слушателя → «Сбросить попытки» |
| Сервер не запускается после правки `content/` | в сообщении об ошибке указан файл и место ошибки; частая причина — двоеточие в тексте YAML без кавычек |
| Коллеги в сети не открывают сайт | запуск без `--host 0.0.0.0` или порт закрыт брандмауэром — раздел 8 |

Если ошибка не описана здесь, создайте обращение на [странице проекта](https://github.com/Toster1012/CardioAI/issues), приложив текст из окна сервера.
