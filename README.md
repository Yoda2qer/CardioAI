# CardioAI: Аналитика данных и машинное обучение

Образовательная платформа для молодых медицинских работников: курс по анализу данных и машинному обучению на реальных открытых кардиологических данных — от первой таблицы пациентов до модели прогноза риска и кривых выживаемости.

> [!IMPORTANT]
> Курс учебный. Модели и выводы из уроков не предназначены для принятия клинических решений.

## Курс

| Раздел | Уроков | Практик |
|---|---|---|
| 1. Медицинские данные и разведочный анализ | 7 | 2 |
| 2. Статистика и подготовка признаков | 6 | 2 |
| 3. Классические модели прогноза риска | 7 | 3 |
| 4. Оценка, валидация и интерпретация моделей | 6 | 2 |
| 5. Выживаемость и ИИ в клинической практике | 7 | 2 |

В каждом разделе — домашнее задание, после него тест из 15 вопросов (проходной балл 80%, три попытки, затем пауза 24 часа) и рефлексия. В конце — итоговый тест из 20 вопросов и сертификат с номером, подлинность которого можно проверить на сайте. Общий объём — 12 академических часов.

Данные: **Heart Failure Clinical Records** (299 пациентов с сердечной недостаточностью) и **Heart Disease** (920 пациентов четырёх клиник, обследованных на ИБС) из UCI Machine Learning Repository. Все числа и графики в уроках получены тем же кодом, который показан слушателю.

## Возможности платформы

- обычная регистрация по email и паролю с согласием на обработку персональных данных, смена и сброс пароля;
- строгий порядок прохождения: урок открывает следующий, тест — следующий раздел;
- практические задания с редактором кода: Python работает прямо в браузере (Pyodide), решение проверяется на сервере с подсказками по каждому пункту;
- домашние задания с проверкой преподавателем, рефлексия по каждому блоку, итоговый тест — модуль на 12 академических часов;
- панель преподавателя: прогресс слушателей, их код, попытки тестов, проверка домашних заданий, ответы рефлексии, временные пароли;
- песочница Python для самостоятельной работы, страница «О курсе» с учебным планом и моделью встраивания в учебный процесс;
- светлая и тёмная темы, адаптивная вёрстка;
- офлайн-режим для закрытой сети учреждения.

## Быстрый старт

Нужен Python 3.11 или новее.

```bash
git clone https://github.com/Toster1012/CardioAI.git
cd CardioAI
```

Windows — `run.bat` (двойной щелчок или `.\run.bat` в терминале), macOS и Linux — `./run.sh`. Скрипт установит зависимости, попросит создать администратора и запустит сайт на http://localhost:8000.

Подробная инструкция — [INSTALL.md](INSTALL.md), она же в PDF: [docs/INSTALL.pdf](docs/INSTALL.pdf).

## Устройство

```
app/            сервер FastAPI: маршруты, модели базы, шаблоны, стили, скрипты
content/        содержимое курса: уроки (Markdown), практики и тесты (YAML)
data/raw/       исходные файлы датасетов UCI без изменений
scripts/        подготовка данных, синхронизация вывода в уроках, офлайн-Pyodide, сборка PDF
tests/          автотесты платформы и содержимого курса
manage.py       служебные команды: база, администратор, запуск
```

Тесты: `pip install -r requirements-dev.txt`, затем `python -m pytest`.
