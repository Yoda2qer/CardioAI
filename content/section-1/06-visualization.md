Таблица из трёхсот строк не помещается в голове, а график — помещается. Визуализация нужна аналитику дважды: в начале работы, чтобы самому увидеть данные, и в конце, чтобы показать вывод другим. В этом уроке разберём четыре вида графиков, которых хватает для большинства клинических задач.

## Зачем смотреть на данные

Сводные числа могут обманывать. Известный пример — «квартет Энскомба»: четыре набора точек с одинаковыми средними, дисперсиями и корреляцией, которые на графике выглядят совершенно по-разному — прямая, дуга, прямая с одним выбросом и вертикальный столбик. Среднее и стандартное отклонение не расскажут, что распределение двугорбое, что в данных есть невозможные значения или что связь нелинейна. График покажет это за секунду.

Выбор графика определяется вопросом.

| Вопрос | График |
|---|---|
| Как распределён один количественный показатель? | гистограмма |
| Различается ли показатель между группами? | ящик с усами (boxplot) |
| Как различается доля или количество по категориям? | столбчатая диаграмма |
| Как связаны два количественных показателя? | диаграмма рассеяния |

## Гистограмма: форма распределения

Гистограмма делит диапазон значений на интервалы и показывает, сколько наблюдений попало в каждый.

```python fig=s1-hist-age
import pandas as pd
import matplotlib.pyplot as plt

hf = pd.read_csv("heart_failure.csv")

fig, ax = plt.subplots()
ax.hist(hf["age"], bins=range(40, 100, 5))
ax.set_xlabel("Возраст, лет")
ax.set_ylabel("Число пациентов")
ax.set_title("Возраст пациентов с сердечной недостаточностью")
plt.show()
```

![Гистограмма возраста: больше всего пациентов в интервале 60–65 лет, распределение слегка скошено вправо](/static/img/lessons/s1-hist-age.png)

Границы интервалов заданы явно — по пять лет. Число интервалов влияет на впечатление: слишком мало — теряются детали, слишком много — картина распадается на шум. Попробуйте несколько вариантов, прежде чем делать вывод.

Сравним с креатинином. Слева — обычная шкала, справа — логарифм значения.

```python fig=s1-hist-creatinine
import numpy as np

fig, axes = plt.subplots(1, 2, figsize=(9, 3.6))
axes[0].hist(hf["serum_creatinine"], bins=30)
axes[0].set_xlabel("Креатинин, мг/дл")
axes[0].set_ylabel("Число пациентов")
axes[0].set_title("Исходная шкала")

axes[1].hist(np.log10(hf["serum_creatinine"]), bins=15)
axes[1].set_xlabel("log10(креатинин)")
axes[1].set_title("Логарифмическая шкала")
plt.show()
```

![Две гистограммы креатинина: на исходной шкале почти все значения сжаты у левого края с длинным хвостом вправо, на логарифмической распределение ближе к симметричному](/static/img/lessons/s1-hist-creatinine.png)

На исходной шкале почти все пациенты сжаты в левой части, а несколько значений тянут ось далеко вправо. После логарифмирования распределение становится ближе к симметричному. Такая «скошенность вправо» типична для лабораторных показателей: креатинина, КФК, тропонина, триглицеридов. Её нужно замечать до выбора статистических методов.

## Ящик с усами: сравнение групп

```python fig=s1-box-ef
survived = hf.loc[hf["DEATH_EVENT"] == 0, "ejection_fraction"]
died = hf.loc[hf["DEATH_EVENT"] == 1, "ejection_fraction"]

fig, ax = plt.subplots()
ax.boxplot([survived, died], tick_labels=["Выжили", "Умерли"], widths=0.5)
ax.set_ylabel("Фракция выброса, %")
ax.set_title("У умерших пациентов фракция выброса ниже")
plt.show()
```

![Два ящика с усами: медиана фракции выброса у выживших около 38%, у умерших около 30%](/static/img/lessons/s1-box-ef.png)

Как читать этот график:

- линия внутри ящика — медиана;
- границы ящика — первый и третий квартили, то есть в ящике лежит средняя половина пациентов;
- усы тянутся до крайних значений в пределах полутора межквартильных размахов;
- отдельные точки — выбросы по тому самому правилу 1,5 IQR из прошлого урока.

Ящики заметно смещены друг относительно друга, но перекрываются: фракция выброса связана с исходом, однако по ней одной предсказать судьбу конкретного пациента нельзя.

## Столбчатая диаграмма: доли по категориям

```python fig=s1-bar-ef
hf["ef_group"] = pd.cut(hf["ejection_fraction"], bins=[0, 39, 49, 100],
                        labels=["< 40%", "40–49%", "≥ 50%"])
rate = hf.groupby("ef_group", observed=True)["DEATH_EVENT"].mean() * 100

fig, ax = plt.subplots()
bars = ax.bar(rate.index, rate.values, width=0.6)
ax.bar_label(bars, fmt="%.0f%%")
ax.set_ylim(0, 50)
ax.set_xlabel("Фракция выброса")
ax.set_ylabel("Умерли за время наблюдения, %")
ax.set_title("Летальность по группам фракции выброса")
plt.show()
```

![Столбчатая диаграмма летальности по группам фракции выброса: менее 40% — 40%, 40–49% — 16%, 50% и выше — 23%](/static/img/lessons/s1-bar-ef.png)

Два правила для столбцов.

**Ось начинается с нуля.** Длина столбца кодирует величину; если обрезать ось на 15%, разница между группами зрительно вырастет в разы. Это самый распространённый способ невольно (или намеренно) преувеличить эффект.

**Подписывайте значения**, когда столбцов немного: читателю не придётся прикидывать высоту по сетке.

## Диаграмма рассеяния: связь двух показателей

Перейдём к данным об ишемической болезни сердца и посмотрим, как связаны возраст и максимальная частота сердечных сокращений на нагрузочной пробе.

```python fig=s1-scatter-hd
hd = pd.read_csv("heart_disease.csv")
hd["target"] = (hd["num"] > 0).astype(int)

fig, ax = plt.subplots()
for value, label in [(0, "ИБС нет"), (1, "ИБС есть")]:
    part = hd[hd["target"] == value]
    ax.scatter(part["age"], part["thalach"], s=16, alpha=0.6, label=label)
ax.set_xlabel("Возраст, лет")
ax.set_ylabel("Максимальная ЧСС при нагрузке, уд/мин")
ax.set_title("С возрастом достигнутая ЧСС снижается")
ax.legend()
plt.show()
```

![Диаграмма рассеяния: облако точек наклонено вниз, точки пациентов с ИБС в среднем расположены ниже и правее](/static/img/lessons/s1-scatter-hd.png)

Видны сразу две закономерности: с возрастом достигнутая ЧСС снижается, а пациенты с ИБС в среднем старше и хуже переносят нагрузку — их точки смещены вниз и вправо. Параметр `alpha` делает точки полупрозрачными: там, где они накладываются, цвет становится гуще, и плотные области видны лучше.

Пациенты с пропущенным `thalach` на график не попали — matplotlib молча пропускает такие точки. Помните об этом: график показывает только тех, у кого измерены оба показателя.

## Как сделать график понятным

::: clinic График для доклада
Слайд показывают двадцать секунд. За это время слушатель должен понять, что отложено по осям, какие группы сравниваются и какой из этого вывод. Поэтому заголовок лучше формулировать как вывод («У умерших фракция выброса ниже»), а не как описание («Распределение фракции выброса по исходам»).
:::

- **Подписи осей с единицами измерения.** «Креатинин, мг/дл», а не `serum_creatinine`.
- **Один график — одна мысль.** Если нужно показать два вывода, сделайте два графика.
- **Одна шкала на оси.** Не совмещайте на одном графике две вертикальные оси с разными единицами: соотношение кривых на таком рисунке зависит от выбора масштаба и легко вводит в заблуждение.
- **Постоянные цвета.** Если «умерли» на первом графике оранжевые, они должны быть оранжевыми на всех.
- **Не полагайтесь только на цвет.** Около 8% мужчин плохо различают красный и зелёный. Добавляйте подписи, легенду, разные формы маркеров.
- **Без объёма и круговых диаграмм с десятью секторами.** Трёхмерные столбцы искажают высоту, а углы человек сравнивает хуже, чем длины.

::: summary
- График выбирают по вопросу: распределение — гистограмма, сравнение групп — ящик с усами, доли по категориям — столбцы, связь двух показателей — диаграмма рассеяния.
- Скошенные вправо распределения (креатинин, КФК) лучше видны на логарифмической шкале.
- У столбчатой диаграммы ось начинается с нуля.
- Заголовок-вывод, подписи с единицами, одна шкала на оси, постоянные цвета.
- На графике видны только пациенты без пропусков в показанных признаках.
:::
