Библиотека pandas — основной инструмент для работы с таблицами в Python. Вы уже знакомы с языком, поэтому здесь не будет синтаксиса с нуля: пройдём по операциям, которые нужны в каждом клиническом анализе, и сразу на данных пациентов с сердечной недостаточностью.

import pandas as pd

## Выбор строк и столбцов

Отбор строк по условию — самая частая операция. Условие в квадратных скобках возвращает только те строки, где оно истинно.

```python
severe = hf[(hf["age"] > 70) & (hf["ejection_fraction"] < 30)]
print(len(severe))
print(severe[["age", "ejection_fraction", "serum_creatinine", "DEATH_EVENT"]].head())
```

```output
9
     age  ejection_fraction  serum_creatinine  DEATH_EVENT
0   75.0                 20               1.9            1
6   75.0                 15               1.2            1
48  80.0                 20               4.4            1
59  72.0                 20               1.3            1
67  72.0                 25               1.0            1
```

Три правила, о которые чаще всего спотыкаются:

- условия объединяют операторами `&` (и), `|` (или), `~` (не), а не словами `and` / `or`;
- каждое условие берут в скобки: `(hf["age"] > 70) & (...)`;
- для выбора строк и столбцов одновременно используют `.loc[условие, список_столбцов]`.

То же самое можно записать через `query` — получается ближе к обычной речи:

```python
print(len(hf.query("age > 70 and ejection_fraction < 30")))
```

```output
9
```

## Подсчёт долей

Для бинарного признака, записанного нулями и единицами, **среднее значение равно доле единиц**. Это самый короткий способ получить частоту события.

```python
print("Доля умерших:", round(hf["DEATH_EVENT"].mean(), 3))
print(hf["DEATH_EVENT"].value_counts())
```

```output
Доля умерших: 0.321
DEATH_EVENT
0    203
1     96
Name: count, dtype: int64
```

За время наблюдения умерли 96 из 299 пациентов — 32,1%. Метод `value_counts()` показывает абсолютные числа; с параметром `normalize=True` он вернёт доли.

## Группировка: сравнение подгрупп

Вопрос «различается ли показатель в группах?» в pandas решается связкой `groupby` + агрегирующая функция.

```python
summary = hf.groupby("DEATH_EVENT")[["age", "ejection_fraction", "serum_creatinine"]].median()
print(summary)
```

```output
              age  ejection_fraction  serum_creatinine
DEATH_EVENT                                           
0            60.0               38.0               1.0
1            65.0               30.0               1.3
```

Умершие пациенты в среднем старше, фракция выброса у них ниже, а креатинин выше. Это пока только описание: достаточно ли велика разница, чтобы не объяснять её случайностью, покажут статистические тесты во втором разделе.

Несколько показателей сразу даёт `agg`:

```python
print(hf.groupby("sex")["DEATH_EVENT"].agg(["size", "sum", "mean"]).round(3))
```

```output
     size  sum   mean
sex                  
0     105   34  0.324
1     194   62  0.320
```

Здесь `size` — число пациентов в группе, `sum` — число умерших, `mean` — их доля. Летальность у женщин (0) и мужчин (1) практически одинакова.

## Новые столбцы и категории

Клиницисты редко мыслят непрерывной фракцией выброса — обычно используют категории. Метод `pd.cut` превращает число в интервал.

```python
hf["ef_group"] = pd.cut(
    hf["ejection_fraction"],
    bins=[0, 39, 49, 100],
    labels=["сниженная (<40%)", "умеренно сниженная (40–49%)", "сохранённая (≥50%)"],
)
print(hf.groupby("ef_group", observed=True)["DEATH_EVENT"].agg(["size", "mean"]).round(3))
```

```output
                             size   mean
ef_group                                
сниженная (<40%)              182  0.401
умеренно сниженная (40–49%)    57  0.158
сохранённая (≥50%)             60  0.233
```

Границы в `bins` включаются справа: интервал `(0, 39]` содержит значения до 39 включительно, `(39, 49]` — от 40 до 49. Параметр `observed=True` просит показывать только те категории, которые реально встречаются в данных.

::: clinic Что говорит таблица
У пациентов со сниженной фракцией выброса летальность заметно выше, чем в остальных группах: 40% против 16–23%. А вот различие между двумя другими группами трактовать рано. В них 57 и 60 человек, и один дополнительный исход сдвигает летальность почти на два процентных пункта. Чем меньше группа, тем менее надёжна оценка доли в ней — поэтому размер группы всегда выводят рядом с долей.
:::

Столбец по условию удобно создавать через сравнение — получится логический признак, который легко превратить в 0 и 1:

```python
hf["high_creatinine"] = (hf["serum_creatinine"] > 1.5).astype(int)
print(hf.groupby("high_creatinine")["DEATH_EVENT"].mean().round(3))
```

```output
high_creatinine
0    0.228
1    0.642
Name: DEATH_EVENT, dtype: float64
```

При креатинине выше 1,5 мг/дл умерли 64% пациентов, при более низком — 23%. Почечная функция оказывается одним из самых сильных признаков в этих данных, и мы ещё не раз к ней вернёмся.

## Типичные ошибки

::: warning Изменение «вида» вместо таблицы
Запись `hf[hf["age"] > 70]["ejection_fraction"] = 0` не изменит исходную таблицу: сначала создаётся временная копия отобранных строк, и присваивание уходит в неё. Правильно — одним обращением через `.loc`:

`hf.loc[hf["age"] > 70, "ejection_fraction"] = 0`

Тот же принцип для новых таблиц: если вы отобрали часть строк и собираетесь её менять, сохраните её в отдельную переменную и работайте с ней.
:::

Ещё две ловушки:

- **Потеря строк при фильтрации.** После каждого отбора проверяйте `len()` — так вы заметите, что условие отсекло больше или меньше, чем ожидалось.
- **Сравнение с пропуском.** Любое сравнение с пустым значением ложно: пациент с неизвестным холестерином не попадёт ни в группу `chol > 200`, ни в группу `chol <= 200`. В Heart Failure пропусков нет, но в Heart Disease это станет важным.

::: summary
- `info()` и `describe()` — первые две команды для любой новой таблицы.
- Отбор строк: условия в скобках, объединённые `&` и `|`, или метод `query`.
- Среднее бинарного столбца — это доля единиц.
- `groupby` + `agg` сравнивает подгруппы; всегда смотрите на размер группы вместе с долей.
- `pd.cut` превращает количественный показатель в клинические категории.
- Изменять значения по условию нужно через `.loc`, одним обращением.
:::
