Кривая Каплана—Мейера — самый известный график клинической медицины: ступенчатая линия, опускающаяся вниз с течением времени, есть почти в каждой статье об исходах лечения. В этом уроке разберём, как она строится с учётом цензурирования, как её читать и как статистически сравнить две кривые.

## Идея метода

Оценить вероятность прожить 250 дней напрямую нельзя: многие пациенты не наблюдались так долго. Метод Каплана—Мейера разбивает задачу на шаги. В каждый момент, когда кто-то умирает, считается условная вероятность пережить этот момент среди тех, кто ещё под наблюдением:

`вероятность пережить момент = 1 − (умерло в этот момент) / (было под наблюдением)`.

Вероятность дожить до t — произведение таких вероятностей по всем моментам до t. Цензурированный пациент участвует в знаменателе, пока наблюдается, и молча выбывает после — без предположений о его судьбе.

Пример: под наблюдением 10 человек. На 5-й день умирает один — выживаемость 9/10 = 0,90. На 7-й день один выбывает живым — выживаемость не меняется, но под наблюдением остаётся 8. На 9-й день умирает ещё один — выживаемость 0,90 × 7/8 ≈ 0,79.

## Кривая для всех пациентов

В Python кривую Каплана—Мейера строит класс `SurvfuncRight` из statsmodels.

```python
import numpy as np
import pandas as pd
from statsmodels.duration.survfunc import SurvfuncRight

hf = pd.read_csv("heart_failure.csv")
km = SurvfuncRight(hf["time"], hf["DEATH_EVENT"])
print(km.summary().head(6))
```

```output
      Surv prob  Surv prob SE  num at risk  num events
Time                                                  
4      0.996656      0.003339          299         1.0
6      0.993311      0.004714          298         1.0
7      0.986622      0.006644          297         2.0
8      0.979933      0.008110          295         2.0
10     0.959866      0.011351          293         6.0
11     0.953177      0.012217          287         2.0
```

В таблице для каждого момента смерти — оценка выживаемости, её стандартная ошибка, число пациентов под наблюдением (`num at risk`) и число событий. Напишем функцию, которая возвращает выживаемость на заданный день: это последнее значение кривой не позже этого дня.

```python
def survival_at(km, day):
    steps = km.surv_times <= day
    return km.surv_prob[steps][-1] if steps.any() else 1.0

for day in [30, 90, 180, 250]:
    print(f"Выживаемость к {day:3} дню: {survival_at(km, day):.1%}")
print("Доля умерших без учёта цензурирования:", f"{hf['DEATH_EVENT'].mean():.1%}")
```

```output
Выживаемость к  30 дню: 88.2%
Выживаемость к  90 дню: 76.3%
Выживаемость к 180 дню: 65.4%
Выживаемость к 250 дню: 57.6%
Доля умерших без учёта цензурирования: 32.1%
```

К 250-му дню, по оценке Каплана—Мейера, в живых остаётся 58% пациентов, то есть смертность — 42%. Наивный подсчёт давал 32%: это и есть ошибка, о которой шла речь в прошлом уроке.

```python fig=s5-km-overall
                step="post", alpha=0.2, label="95% доверительный интервал")
ax.set_ylim(0, 1.02)
ax.set_xlabel("Дни наблюдения")
ax.set_ylabel("Доля живых")
ax.set_title("Выживаемость пациентов с сердечной недостаточностью")
ax.legend(loc="lower left")

```

![Ступенчатая кривая выживаемости, опускающаяся от 1 до примерно 0,58 к 250-му дню, с расширяющейся к концу затенённой полосой доверительного интервала](/static/img/lessons/s5-km-overall.png)

Обратите внимание, как расширяется доверительный интервал к правому краю: под наблюдением остаётся всё меньше пациентов, и оценка становится всё менее точной. Правый «хвост» кривой Каплана—Мейера всегда нужно читать осторожно.

**Медиана выживаемости** — время, к которому кривая опускается до 0,5. Здесь кривая до этого уровня не доходит: больше половины пациентов пережили весь срок наблюдения, и медиана «не достигнута». Это обычная ситуация, а не ошибка.

## Сравнение двух групп

Разделим пациентов по уровню креатинина и построим кривые для каждой группы.

```python fig=s5-km-creatinine
high = hf["serum_creatinine"] > 1.5
groups = {"Креатинин ≤ 1,5 мг/дл": hf[~high], "Креатинин > 1,5 мг/дл": hf[high]}

fig, ax = plt.subplots()
for label, group in groups.items():
    km_group = SurvfuncRight(group["time"], group["DEATH_EVENT"])
    ax.step(np.r_[0, km_group.surv_times], np.r_[1, km_group.surv_prob], where="post",
            label=f"{label} (n = {len(group)})")
    print(f"{label}: выживаемость к 250 дню {survival_at(km_group, 250):.1%}, медиана {km_group.quantile(0.5)}")
ax.set_ylim(0, 1.02)
ax.set_xlabel("Дни наблюдения")
ax.set_ylabel("Доля живых")
ax.set_title("При повышенном креатинине выживаемость резко ниже")
ax.legend(loc="lower left")
plt.show()
```

```output
Креатинин ≤ 1,5 мг/дл: выживаемость к 250 дню 70.4%, медиана nan
Креатинин > 1,5 мг/дл: выживаемость к 250 дню 23.3%, медиана 113
```

## Лог-ранговый тест

Различаются ли кривые неслучайно? Стандартный способ проверить — **лог-ранговый тест**. Он в каждый момент смерти сравнивает наблюдаемое число событий в группе с ожидаемым, если бы риск в группах был одинаков, и суммирует расхождения по всему периоду.

```python
from statsmodels.duration.survfunc import survdiff

chi2, p = survdiff(hf["time"], hf["DEATH_EVENT"], high.astype(int))
print(f"Лог-ранговый тест: хи-квадрат = {chi2:.1f}, p = {p:.1g}")
```

```output
Лог-ранговый тест: хи-квадрат = 39.6, p = 3e-10
```

Различие, разумеется, значимо. Лог-ранговый тест чувствителен прежде всего к ситуации, когда одна кривая стабильно ниже другой. Если кривые пересекаются — например, операция повышает риск в первые дни, но улучшает отдалённый прогноз, — тест может не заметить реальной разницы.

::: clinic Как читать кривые в статьях
Под качественным графиком Каплана—Мейера приводят таблицу «число под риском» — сколько пациентов наблюдалось в каждой группе к отметкам времени. Если к концу графика под наблюдением осталось пять человек, резкая ступенька в правой части означает смерть одного-двух пациентов, а не тенденцию. Смотрите на расхождение кривых там, где пациентов ещё много, и на доверительные интервалы.
:::

## Ограничения

- **Одна переменная за раз.** Кривые для «высокого» и «нормального» креатинина не учитывают, что эти группы различаются ещё и возрастом, фракцией выброса и всем остальным. Для учёта нескольких факторов одновременно нужна модель Кокса — тема следующего теоретического урока.
- **Нужны группы.** Количественный показатель приходится разрезать на категории, теряя информацию; выбор порога влияет на результат.
- **Неинформативное цензурирование** остаётся главным допущением.

::: summary
- Метод Каплана—Мейера перемножает условные вероятности пережить каждый момент смерти; цензурированные пациенты учитываются, пока наблюдаются.
- Оценка Каплана—Мейера учитывает цензурирование: здесь смертность к 250 дню — 42% против наивных 32%.
- Медиана выживаемости — время, когда кривая пересекает 0,5; она может быть не достигнута.
- Правый край кривой ненадёжен: под наблюдением мало пациентов.
- Лог-ранговый тест сравнивает кривые групп; при пересекающихся кривых он теряет чувствительность.
:::
