Кривые Каплана—Мейера сравнивают группы по одному признаку. Но пациенты с высоким креатинином ещё и старше, и фракция выброса у них ниже — какой из факторов на самом деле связан с прогнозом? Модель пропорциональных рисков Кокса делает для данных о выживаемости то же, что логистическая регрессия для бинарного исхода: оценивает вклад каждого фактора при учёте остальных.

## Отношение рисков

Модель Кокса описывает не вероятность события, а **риск** — мгновенную интенсивность событий среди доживших. Она предполагает, что риск пациента равен некоторому общему для всех базовому риску, умноженному на множитель, который зависит от признаков:

`h(t | признаки) = h0(t) × exp(b1 × возраст + b2 × фракция выброса + …)`

Базовый риск h0(t) может как угодно меняться со временем, и модели не нужно знать его форму. Экспонента коэффициента — **отношение рисков** (hazard ratio, HR): во сколько раз выше мгновенный риск при увеличении признака на единицу и неизменных остальных.

## Обучим модель

В statsmodels модель Кокса строится функцией `phreg`. Формула описывает признаки, а время и индикатор события передаются отдельно.

```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

hf = pd.read_csv("heart_failure.csv")
formula = ("time ~ age + ejection_fraction + serum_creatinine + serum_sodium"
           " + anaemia + high_blood_pressure")
result = smf.phreg(formula, hf, status=hf["DEATH_EVENT"].to_numpy()).fit()
params = pd.Series(result.params, index=result.model.exog_names)

ci = np.exp(result.conf_int())
table = pd.DataFrame({
    "HR": np.exp(params),
    "ДИ нижн.": ci[:, 0],
    "ДИ верхн.": ci[:, 1],
    "p": result.pvalues,
}, index=result.model.exog_names)
print(table.round(3))
```

```output
                        HR  ДИ нижн.  ДИ верхн.      p
age                  1.045     1.026      1.063  0.000
ejection_fraction    0.954     0.936      0.974  0.000
serum_creatinine     1.343     1.172      1.538  0.000
serum_sodium         0.957     0.914      1.003  0.065
anaemia              1.454     0.963      2.195  0.075
high_blood_pressure  1.599     1.054      2.427  0.027
```

Читаем так же, как отношения шансов. Каждый год возраста увеличивает мгновенный риск смерти примерно на 4–5%, каждый процентный пункт фракции выброса снижает его на 5%. Повышение креатинина на 1 мг/дл увеличивает риск на треть. У натрия и анемии доверительные интервалы включают единицу.

Интересно поведение гипертензии. Во втором разделе тест хи-квадрат не нашёл связи гипертензии с фактом смерти (p = 0,21). Модель Кокса находит повышение риска в 1,6 раза. Причина в том, что модель использует больше информации: не только *умер ли* пациент, но и *как скоро*, и сравнивает пациентов при равных прочих факторах. Это не значит, что один из результатов «правильный»: при p около 0,03 и широком интервале от 1,05 до 2,4 эту находку разумно считать гипотезой для проверки на других данных.

Как и для отношения шансов, эффект на несколько единиц получают возведением в степень:

```python
hr = np.exp(params)
print(f"HR на 10 лет возраста: {hr['age'] ** 10:.2f}")
print(f"HR на 10 п. п. фракции выброса: {hr['ejection_fraction'] ** 10:.2f}")
```

```output
HR на 10 лет возраста: 1.55
HR на 10 п. п. фракции выброса: 0.63
```

::: note Отношение рисков и отношение шансов
Отношение шансов из логистической регрессии описывает итог за весь период наблюдения и не учитывает, кто сколько наблюдался. Отношение рисков сравнивает интенсивность событий в каждый момент времени и корректно работает с цензурированием. Для данных с разным сроком наблюдения модель Кокса — правильный выбор.
:::

## Прогноз для конкретных пациентов

Модель позволяет сравнить двух пациентов: отношение их рисков — экспонента разности линейных предикторов. Возьмём пожилого пациента с низкой фракцией выброса и нарушенной функцией почек и пациента помоложе с умеренными показателями.

```python
patients = pd.DataFrame([
    {"age": 75, "ejection_fraction": 25, "serum_creatinine": 2.0, "serum_sodium": 133,
     "anaemia": 1, "high_blood_pressure": 1},
    {"age": 55, "ejection_fraction": 45, "serum_creatinine": 1.0, "serum_sodium": 138,
     "anaemia": 0, "high_blood_pressure": 0},
])
linear = patients[result.model.exog_names].to_numpy() @ result.params
print(f"Риск первого пациента выше в {np.exp(linear[0] - linear[1]):.1f} раза")
```

```output
Риск первого пациента выше в 23.6 раза
```

Чтобы получить не относительный, а абсолютный прогноз — кривую выживаемости, — к отношению рисков добавляют оценку базового риска.

```python fig=s5-cox-curves
import matplotlib.pyplot as plt

times, cumulative_hazard, _ = result.baseline_cumulative_hazard[0]
fig, ax = plt.subplots()
labels = ["75 лет, ФВ 25%, креатинин 2,0", "55 лет, ФВ 45%, креатинин 1,0"]
colors = ["#eb6834", "#2a78d6"]
for label, color, lp in zip(labels, colors, linear):
    survival = np.exp(-cumulative_hazard * np.exp(lp))
    ax.step(np.r_[0, times], np.r_[1, survival], where="post", color=color, label=label)
ax.set_ylim(0, 1.02)
ax.set_xlabel("Дни наблюдения")
ax.set_ylabel("Предсказанная доля живых")

ax.legend(loc="lower left")

```

## Насколько хорошо модель различает пациентов

Аналог AUC для данных о выживаемости — **индекс согласованности** (C-индекс). Он равен доле пар пациентов, в которых модель правильно определила, кто из двоих умрёт раньше. Учитываются только пары, где это можно установить: один умер, а другой к этому моменту ещё наблюдался.

```python
def concordance_index(time, event, risk):
    time, event, risk = map(np.asarray, (time, event, risk))
    concordant = comparable = 0.0
    for i in np.flatnonzero(event):
        later = time > time[i]
        comparable += later.sum()
        concordant += (risk[i] > risk[later]).sum() + 0.5 * (risk[i] == risk[later]).sum()
    return concordant / comparable

risk_score = result.model.exog @ result.params
print(f"C-индекс: {concordance_index(hf['time'], hf['DEATH_EVENT'], risk_score):.3f}")
```

```output
C-индекс: 0.729
```

Значение около 0,73 — приемлемое, но далёкое от идеала: по этим признакам порядок смертей угадывается в трёх парах из четырёх. Помните, что это оценка на тех же данных, на которых модель обучена, — то есть оптимистичная.

## Главное допущение: пропорциональность рисков

Модель предполагает, что отношение рисков **постоянно во времени**: если креатинин увеличивает риск на треть, то и на первой неделе, и через полгода. Графически это значит, что кривые Каплана—Мейера для групп не пересекаются и расходятся постепенно.

Формальная проверка использует остатки Шёнфельда: если допущение выполнено, они не должны меняться со временем.

```python
from scipy import stats

residuals = result.schoenfeld_residuals
died = hf["DEATH_EVENT"].to_numpy() == 1
event_times = hf["time"].to_numpy()[died]
for name, column in zip(result.model.exog_names, residuals.T):
    r, p = stats.spearmanr(column[died], event_times)
    print(f"{name:20} связь остатков со временем: r = {r:5.2f}, p = {p:.3f}")
```

```output
age                  связь остатков со временем: r =  0.01, p = 0.940
ejection_fraction    связь остатков со временем: r = -0.21, p = 0.038
serum_creatinine     связь остатков со временем: r =  0.40, p = 0.000
serum_sodium         связь остатков со временем: r = -0.00, p = 0.971
anaemia              связь остатков со временем: r =  0.35, p = 0.001
high_blood_pressure  связь остатков со временем: r =  0.36, p = 0.000
```

Для возраста и натрия связи нет, для фракции выброса она слабая. А вот для креатинина, анемии и гипертензии остатки заметно меняются со временем: похоже, влияние этих факторов в течение наблюдения не постоянно, а усиливается. Значит, их отношения рисков из таблицы — это усреднение за весь период, и толковать их нужно осторожно. Например, «гипертензия повышает риск в 1,6 раза» может на деле означать «почти не влияет в первые недели и заметно влияет позже». В исследовании для публикации такие признаки моделируют с зависящим от времени эффектом или делят наблюдение на периоды. Проверка допущений — не формальность: она меняет то, что можно утверждать по результатам модели.

::: warning Когда модель Кокса вводит в заблуждение
Классический пример нарушения — хирургическое лечение: в первые дни после операции риск выше, чем при консервативном ведении, а в отдалённом периоде ниже. Единое отношение рисков усредняет эти противоположные эффекты в бессмысленное «примерно одинаково». В таких случаях анализ делят на периоды или вводят зависящие от времени эффекты.
:::

::: summary
- Модель Кокса оценивает отношение рисков для каждого фактора при учёте остальных и корректно работает с цензурированием.
- HR > 1 — фактор повышает мгновенный риск события, HR < 1 — снижает; интервал, включающий 1, не позволяет говорить о связи.
- Абсолютный прогноз получают, сочетая отношение рисков с базовым риском.
- C-индекс — доля пар, правильно упорядоченных по времени события; аналог AUC.
- Главное допущение — постоянство отношения рисков во времени; его проверяют по кривым и остаткам Шёнфельда.
:::
