Модель учится на данных, а данные — это след того, как работала медицина в конкретном месте и в конкретное время. Всё, что в этой работе было неравномерным, модель усвоит вместе с закономерностями болезни. Этот урок о том, откуда берутся смещения, как проверить модель на справедливость и почему «хороший AUC в среднем» не гарантирует хорошей работы для каждого пациента.

## Откуда берутся смещения

**Смещение отбора.** В данные попадают не все пациенты, а те, кто дошёл до обследования. Наши 920 человек с подозрением на ИБС — это люди, которых направили на коронарную ангиографию в 1980-е годы. Почти восемь из десяти — мужчины: в те годы ИБС считали преимущественно мужской болезнью, и женщин с похожими симптомами, по-видимому, направляли на обследование реже.

**Смещение измерения.** Один и тот же показатель по-разному измеряют в разных местах: разные лаборатории, разные протоколы, записанный нулём холестерин в Швейцарии.

**Смещение разметки.** Модель учится предсказывать не болезнь, а *зафиксированный диагноз*. Если у какой-то группы болезнь диагностируют позже или реже, модель выучит именно это «реже».

**Сдвиг данных.** Популяция, методы лечения и оборудование меняются. Модель, обученная на пациентах 1980-х, ничего не знает о современных стентах и статинах.

## Проверка по подгруппам

Посмотрим, как модель диагностики ИБС работает для мужчин и для женщин. Чтобы получить честные оценки для каждого пациента, используем перекрёстную проверку: каждый прогноз сделан моделью, которая этого пациента не видела.

```python
import numpy as np
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score
from sklearn.model_selection import StratifiedKFold, cross_val_predict
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler

hd = pd.read_csv("heart_disease.csv")
hd[["chol", "trestbps"]] = hd[["chol", "trestbps"]].replace(0, np.nan)
hd["target"] = (hd["num"] > 0).astype(int)
numeric = ["age", "trestbps", "chol", "thalach", "oldpeak"]

def make_model(binary):
    preprocess = ColumnTransformer([
        ("num", Pipeline([("imputer", SimpleImputer(strategy="median")),
                          ("scaler", StandardScaler())]), numeric),
        ("cat", Pipeline([("imputer", SimpleImputer(strategy="most_frequent")),
                          ("onehot", OneHotEncoder(handle_unknown="ignore", sparse_output=False))]), ["cp"]),
        ("bin", SimpleImputer(strategy="most_frequent"), binary),
    ])
    return Pipeline([("prep", preprocess), ("clf", LogisticRegression(max_iter=1000))])

def subgroup_report(proba):
    rows = []
    for sex, group in hd.assign(proba=proba).groupby("sex"):
        predicted = group["proba"] >= 0.5
        sick = group["target"] == 1
        rows.append({
            "группа": "мужчины" if sex == 1 else "женщины",
            "пациентов": len(group),
            "доля ИБС": round(sick.mean(), 3),
            "средний прогноз": round(group["proba"].mean(), 3),
            "AUC": round(roc_auc_score(sick, group["proba"]), 3),
            "чувствительность": round((predicted & sick).sum() / sick.sum(), 3),
            "специфичность": round((~predicted & ~sick).sum() / (~sick).sum(), 3),
        })
    return pd.DataFrame(rows).to_string(index=False)

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
features = numeric + ["cp", "sex", "exang"]
proba = cross_val_predict(make_model(["sex", "exang"]), hd[features], hd["target"],
                          cv=cv, method="predict_proba")[:, 1]
print(subgroup_report(proba))
```

```output
 группа  пациентов  доля ИБС  средний прогноз   AUC  чувствительность  специфичность
женщины        194     0.258            0.267 0.860             0.620          0.910
мужчины        726     0.632            0.629 0.858             0.861          0.652
```

AUC у мужчин и женщин почти одинаков: модель одинаково хорошо *упорядочивает* пациентов внутри каждой группы. Средний прогноз совпадает с реальной долей больных — с калибровкой тоже всё в порядке. Но при общем пороге 0,5 картина другая: у женщин модель находит лишь около 60% больных, у мужчин — 86%.

Причина — в распространённости. В этих данных ИБС подтверждена у четверти женщин и почти у двух третей мужчин. Модель честно выучила это различие, и вероятности у женщин в среднем ниже — реже переходят порог. Каждая отдельная оценка верна, а последствия для двух групп разные: больная женщина с тем же набором симптомов получит «отрицательный» ответ заметно чаще больного мужчины.

## Помогает ли убрать признак?

Первое, что приходит в голову, — исключить пол из модели.

```python
features_no_sex = numeric + ["cp", "exang"]
proba_no_sex = cross_val_predict(make_model(["exang"]), hd[features_no_sex], hd["target"],
                                 cv=cv, method="predict_proba")[:, 1]
print(subgroup_report(proba_no_sex))
```

```output
 группа  пациентов  доля ИБС  средний прогноз   AUC  чувствительность  специфичность
женщины        194     0.258            0.424 0.863             0.820          0.764
мужчины        726     0.632            0.587 0.857             0.815          0.723
```

Чувствительность выровнялась. Но посмотрите на средний прогноз у женщин: модель теперь ожидает больных заметно больше, чем их есть, — она перестала быть откалиброванной для этой группы и чаще поднимает ложную тревогу. Убрав признак, мы не устранили различие, а переложили его в другой вид ошибок.

::: note Справедливость не сводится к одному числу
Можно требовать равной чувствительности в группах, равной специфичности, равной прогностической ценности или хорошей калибровки в каждой группе. Когда распространённость болезни в группах различается, все эти требования одновременно выполнить невозможно — это математический факт, а не недостаток конкретной модели. Выбор того, какое равенство важнее, — клиническое и этическое решение, а не техническое.
:::

## Что делать на практике

- **Всегда отчитываться по подгруппам**: пол, возраст, место лечения, а где это уместно — социальные и этнические группы. Средний показатель скрывает различия.
- **Проверять представленность.** Если женщин в обучающих данных четверть, а среди тех, к кому модель будут применять, — половина, это повод для отдельной проверки.
- **Выбирать порог осознанно.** При необходимости — с учётом подгруппы и цены ошибок для неё, обсуждая решение с клиницистами.
- **Помнить о прокси-признаках.** Даже без «пола» в модели остаются признаки, связанные с ним: рост, гемоглобин, профессия. Модель может восстановить группу косвенно.
- **Не путать различие с несправедливостью.** Разная распространённость болезни — реальность; несправедливость возникает, когда модель систематически хуже служит одной группе без медицинского обоснования.

::: clinic Пример из истории медицины
Многие формулы и шкалы десятилетиями включали поправки на расу — например, формулы расчёта скорости клубочковой фильтрации. В результате у части пациентов функция почек оценивалась как лучшая, чем у других при тех же лабораторных показателях, и их позже направляли к нефрологу и в лист ожидания трансплантации. В 2021 году ведущие нефрологические общества США рекомендовали формулу без расового коэффициента. Урок для моделей ИИ тот же: признак, который «улучшает точность в среднем», может систематически вредить конкретной группе.
:::

## Автоматизационное смещение

Последний источник смещения — не в модели, а в человеке. Врачи склонны чрезмерно доверять подсказке компьютера: соглашаться с ней, даже когда собственные наблюдения говорят обратное, и меньше перепроверять. Чем удобнее и «увереннее» выглядит интерфейс, тем сильнее этот эффект. Модель должна поддерживать клиническое мышление, а не заменять его.

::: summary
- Смещения возникают при отборе пациентов, измерении, постановке диагноза и со временем; модель усваивает их вместе с закономерностями.
- Качество модели проверяют отдельно в подгруппах: одинаковый AUC не означает одинаковых последствий.
- При разной распространённости болезни общий порог даёт группам разную чувствительность.
- Удаление «чувствительного» признака не устраняет различие, а переносит его в другой вид ошибок.
- Разные критерии справедливости при разной распространённости несовместимы; выбор между ними — клиническое и этическое решение.
:::
