## Задание

Используйте пациентов **Кливлендской клиники** из `heart_disease.csv` (`clinic == "cleveland"`). Целевая группа — пациенты с подтверждённой ИБС (`num > 0`), группа сравнения — без неё.

1. Выберите **шесть признаков**: три количественных и три категориальных или бинарных.
2. Для каждого признака выберите **способ описания** (среднее ± SD, медиана [Q1; Q3] или n (%)) и объясните выбор: посмотрите на форму распределения.
3. Для каждого признака выберите и примените **статистический тест** (t-критерий Уэлча, Манна—Уитни, хи-квадрат) и укажите p-значение.
4. Примените **поправку Бонферрони** на шесть сравнений и отметьте признаки, различия по которым остаются значимыми.
5. Для одного количественного признака приведите **разность между группами с 95% доверительным интервалом**.
6. **Интерпретация.** 4–6 предложений: какие различия клинически значимы, а какие лишь статистически; какие конфаундеры могли повлиять на результат.

## Критерии оценки

| Критерий | Что проверяется |

| Описание | способ описания соответствует распределению признака |
| Тесты | тест соответствует типу признака и распределению |
| Множественные сравнения | поправка применена и учтена в выводах |
