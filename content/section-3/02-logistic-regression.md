Логистическая регрессия — самый распространённый метод в клинических исследованиях и разумная отправная точка для любой задачи прогноза. Большинство шкал риска, которыми вы пользуетесь, построены именно на ней. Её главное достоинство — результат можно прочитать: у каждого фактора есть коэффициент с понятным смыслом.

## От вероятности к шансам

Вероятность лежит между 0 и 1, а обычная линейная формула может дать и −3, и 15. Чтобы связать одно с другим, вероятность преобразуют в два шага.

**Шансы** — отношение вероятности события к вероятности его отсутствия: `шансы = p / (1 − p)`. При вероятности смерти 20% шансы равны 0,2 / 0,8 = 0,25, или «один к четырём». При 50% шансы равны 1, при 80% — 4.

**Логарифм шансов** (логит) уже может быть любым числом. Логистическая регрессия предполагает, что именно он линейно зависит от признаков:

`логарифм шансов = b0 + b1 × возраст + b2 × фракция выброса + …`

Обратное преобразование — S-образная кривая (сигмоида) — превращает результат формулы обратно в вероятность от 0 до 1.

## Обучим модель

Для анализа факторов риска удобна библиотека statsmodels: она сразу даёт доверительные интервалы и p-значения. Возьмём четыре показателя, которые различались между группами во втором разделе.

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

hf = pd.read_csv("heart_failure.csv")
predictors = ["age", "ejection_fraction", "serum_creatinine", "serum_sodium"]

X = sm.add_constant(hf[predictors])
result = sm.Logit(hf["DEATH_EVENT"], X).fit(disp=0)

table = pd.DataFrame({
    "коэффициент": result.params,
    "ОШ": np.exp(result.params),
    "ДИ нижн.": np.exp(result.conf_int()[0]),
    "ДИ верхн.": np.exp(result.conf_int()[1]),
    "p": result.pvalues,
}).drop(index="const")
print(table.round(3))
```

```output
                   коэффициент     ОШ  ДИ нижн.  ДИ верхн.      p
age                      0.051  1.053     1.028      1.079  0.000
ejection_fraction       -0.067  0.936     0.910      0.962  0.000
serum_creatinine         0.632  1.881     1.379      2.566  0.000
serum_sodium            -0.048  0.953     0.895      1.016  0.141
```

Функция `add_constant` добавляет свободный член `b0` — без него модель предполагала бы, что при нулевых значениях всех признаков шансы равны единице.

## Отношение шансов

Коэффициент показывает, на сколько меняется логарифм шансов при увеличении признака на единицу. Сам по себе он неудобен, поэтому берут экспоненту и получают **отношение шансов** (ОШ) — во сколько раз меняются шансы.

- ОШ = 1 — признак не связан с исходом.
- ОШ > 1 — с ростом признака шансы события растут.
- ОШ < 1 — с ростом признака шансы снижаются.

Читаем таблицу. Каждый дополнительный год возраста увеличивает шансы смерти примерно на 5%. Каждый процентный пункт фракции выброса снижает их на 6%. Повышение креатинина на 1 мг/дл увеличивает шансы почти вдвое. Для натрия доверительный интервал включает единицу: его связь с исходом при учёте трёх других факторов уже неотличима от случайной.

Ключевые слова — **«при прочих равных»**. Эффект креатинина оценён среди пациентов одного возраста, с одинаковой фракцией выброса и натрием. Так многофакторная модель учитывает конфаундеры, о которых шла речь во втором разделе.

Единица измерения признака определяет масштаб ОШ. «5% за год» выглядит скромно, но за десять лет эффект накапливается перемножением:

```python
or_age = np.exp(result.params["age"])
or_ef = np.exp(result.params["ejection_fraction"])
print(f"ОШ на 10 лет возраста: {or_age ** 10:.2f}")
print(f"ОШ на 10 п. п. фракции выброса: {or_ef ** 10:.2f}")
```

```output
ОШ на 10 лет возраста: 1.67
ОШ на 10 п. п. фракции выброса: 0.51
```

::: warning Шансы — не риск
«Шансы выросли в 1,9 раза» не означает «риск вырос в 1,9 раза». Когда событие редкое (менее 10%), шансы и риск почти совпадают. Здесь умирает треть пациентов, и отношение шансов заметно преувеличивает изменение риска. При риске 30% удвоение шансов даёт риск 46%, а не 60%.
:::

## Что модель говорит о конкретном пациенте

Посмотрим, как предсказанная вероятность смерти зависит от фракции выброса у пациентов 50 и 75 лет. Креатинин и натрий зафиксируем на медианных значениях.

```python fig=s3-sigmoid
import matplotlib.pyplot as plt

ef_range = np.arange(15, 71)
fig, ax = plt.subplots()
for age in [50, 75]:
    grid = pd.DataFrame({
        "const": 1.0,
        "age": age,
        "ejection_fraction": ef_range,
        "serum_creatinine": hf["serum_creatinine"].median(),
        "serum_sodium": hf["serum_sodium"].median(),
    })
    ax.plot(ef_range, result.predict(grid) * 100, label=f"{age} лет")
ax.set_xlabel("Фракция выброса, %")
ax.set_ylabel("Предсказанная вероятность смерти, %")
ax.set_title("Риск растёт при снижении фракции выброса и с возрастом")
ax.set_ylim(0, 100)
ax.legend(title="Возраст")
plt.show()
```

![Две убывающие кривые предсказанной вероятности смерти в зависимости от фракции выброса: кривая для 75 лет лежит выше кривой для 50 лет на всём диапазоне](/static/img/lessons/s3-sigmoid.png)

Кривые не параллельны и не прямые: один и тот же шаг фракции выброса по-разному меняет вероятность в зависимости от того, с какого уровня риска мы стартуем. Это свойство сигмоиды — постоянным остаётся отношение шансов, а не разность вероятностей.

## Прогноз в scikit-learn

Когда цель — не изучение факторов, а прогноз, удобнее scikit-learn: модель встраивается в конвейер с подготовкой признаков.

```python
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

model = make_pipeline(StandardScaler(), LogisticRegression())
model.fit(hf[predictors], hf["DEATH_EVENT"])

patient = pd.DataFrame([{
    "age": 72, "ejection_fraction": 25, "serum_creatinine": 2.1, "serum_sodium": 132,
}])
print(f"Вероятность смерти: {model.predict_proba(patient)[0, 1]:.0%}")
```

```output
Вероятность смерти: 75%
```

Метод `predict_proba` возвращает вероятности обоих классов; столбец с индексом 1 — вероятность события. Метод `predict` выдаёт готовый класс, сравнивая вероятность с порогом 0,5; о том, почему этот порог редко оптимален, поговорим в четвёртом разделе.

По умолчанию scikit-learn применяет **регуляризацию** — слегка «прижимает» коэффициенты к нулю, чтобы модель не переобучалась. Силу регуляризации задаёт параметр `C`: чем он меньше, тем она сильнее. Из-за этого коэффициенты scikit-learn и statsmodels немного различаются, и регуляризованной модели нужен масштаб признаков, одинаковый для всех, — отсюда `StandardScaler` в конвейере.

## Ограничения

::: clinic Сколько факторов можно включить в модель
Старое практическое правило — не меньше десяти событий на один предиктор. В наших данных 96 смертей, то есть разумный предел — девять-десять признаков. Модель с тридцатью факторами на таких данных будет уверенно описывать случайный шум.
:::

- **Линейность на шкале логарифма шансов.** Модель считает, что каждый год возраста добавляет одно и то же. Если риск растёт только после 70 лет, она этого не уловит без специальных приёмов.
- **Взаимодействия не учитываются сами.** Если креатинин опасен только при низкой фракции выброса, это нужно задать явно.
- **Чувствительность к коллинеарности.** Связанные между собой признаки делают коэффициенты неустойчивыми.
- **Связь — не причина.** ОШ = 1,9 для креатинина не значит, что его снижение уменьшит риск.

::: summary
- Логистическая регрессия линейно моделирует логарифм шансов и переводит его в вероятность сигмоидой.
- Экспонента коэффициента — отношение шансов при увеличении признака на единицу, при прочих равных.
- ОШ с доверительным интервалом, включающим 1, не позволяет говорить о связи.
- Отношение шансов преувеличивает изменение риска, когда событие частое.
- statsmodels удобен для анализа факторов, scikit-learn — для прогноза в конвейере.
- Число предикторов ограничено числом событий: ориентир — десять событий на признак.
:::
