Логистическая регрессия описывает риск формулой. Два метода этого урока устроены иначе и ближе к тому, как рассуждает врач: метод ближайших соседей ищет похожих пациентов, а дерево решений задаёт последовательность вопросов. Оба просты для понимания, и оба наглядно показывают, как возникает переобучение.

## Метод ближайших соседей

Идея знакома каждому клиницисту: «у меня был похожий больной». Чтобы оценить нового пациента, метод k ближайших соседей (kNN) находит в обучающих данных k самых похожих на него людей и смотрит, какой исход был у большинства.

«Похожесть» — это расстояние между пациентами в пространстве признаков. Здесь и скрывается главная ловушка. Холестерин измеряется сотнями, депрессия ST — единицами; без масштабирования расстояние почти целиком определяется холестерином, а остальные признаки теряются.

```python
import numpy as np
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler

hd = pd.read_csv("heart_disease.csv")
hd[["chol", "trestbps"]] = hd[["chol", "trestbps"]].replace(0, np.nan)
hd["target"] = (hd["num"] > 0).astype(int)

numeric = ["age", "trestbps", "chol", "thalach", "oldpeak"]
X, y = hd[numeric + ["cp", "sex", "exang"]], hd["target"]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

def make_knn(k, scale=True):
    num_steps = [("imputer", SimpleImputer(strategy="median"))]
    if scale:
        num_steps.append(("scaler", StandardScaler()))
    prep = ColumnTransformer([
        ("num", Pipeline(num_steps), numeric),
        ("cat", Pipeline([("imputer", SimpleImputer(strategy="most_frequent")),
                          ("onehot", OneHotEncoder(handle_unknown="ignore", sparse_output=False))]), ["cp"]),
        ("bin", SimpleImputer(strategy="most_frequent"), ["sex", "exang"]),
    ])
    return Pipeline([("prep", prep), ("knn", KNeighborsClassifier(n_neighbors=k))])

for scale in [False, True]:
    model = make_knn(15, scale).fit(X_train, y_train)
    label = "с масштабированием" if scale else "без масштабирования"
    print(f"{label}: доля верных ответов {model.score(X_test, y_test):.3f}")
```

```output
без масштабирования: доля верных ответов 0.674
с масштабированием: доля верных ответов 0.791
```

Одна строка в конвейере — и качество выросло более чем на десять процентных пунктов. Для методов, основанных на расстояниях, масштабирование не формальность, а условие работоспособности.

## Сколько соседей брать

Число соседей k управляет гибкостью модели.

```python fig=s3-knn-k
import matplotlib.pyplot as plt

ks = [1, 3, 5, 9, 15, 25, 41, 61, 101]
train_acc, test_acc = [], []
for k in ks:
    model = make_knn(k).fit(X_train, y_train)
    train_acc.append(model.score(X_train, y_train))
    test_acc.append(model.score(X_test, y_test))

fig, ax = plt.subplots()
ax.plot(ks, train_acc, marker="o", label="Обучающая выборка")
ax.plot(ks, test_acc, marker="o", label="Тестовая выборка")
ax.set_xscale("log")
ax.set_xticks(ks, [str(k) for k in ks])
ax.set_xlabel("Число соседей k")
ax.set_ylabel("Доля верных ответов")
ax.set_title("При k = 1 модель запоминает обучающие данные")
ax.legend()
plt.show()
```

![Две линии доли верных ответов в зависимости от числа соседей: на обучающей выборке она падает от 1,0 при k = 1 до примерно 0,78, на тестовой держится около 0,8](/static/img/lessons/s3-knn-k.png)

При k = 1 каждый обучающий пациент — ближайший сосед самому себе, поэтому на обучающей выборке модель не ошибается никогда. Это переобучение в чистом виде: огромный разрыв между линиями. С ростом k линии сближаются — модель усредняет всё больше пациентов и перестаёт реагировать на случайности. Если взять k слишком большим, она начнёт игнорировать и настоящие различия.

У метода есть два практических недостатка. Он ничего не «выучивает» заранее, а хранит всю обучающую выборку — то есть данные пациентов нужны при каждом прогнозе. И он не объясняет ответ: «пятнадцать похожих больных» — не то же самое, что «риск повышен из-за низкой фракции выброса».

## Дерево решений

Дерево решений — это блок-схема из вопросов «да или нет». Обучим неглубокое дерево на данных о сердечной недостаточности. Срок наблюдения `time` в признаки не включаем: он становится известен только вместе с исходом, и к этой ловушке мы вернёмся в четвёртом разделе.

```python
from sklearn.tree import DecisionTreeClassifier, export_text

hf = pd.read_csv("heart_failure.csv")
hf_features = [c for c in hf.columns if c not in ("time", "DEATH_EVENT")]
Xh_train, Xh_test, yh_train, yh_test = train_test_split(
    hf[hf_features], hf["DEATH_EVENT"], test_size=0.3, random_state=0, stratify=hf["DEATH_EVENT"]
)

tree = DecisionTreeClassifier(max_depth=2, random_state=0).fit(Xh_train, yh_train)
print(export_text(tree, feature_names=hf_features))
```

```output
|--- ejection_fraction <= 27.50
|   |--- serum_creatinine <= 0.85
|   |   |--- class: 0
|   |--- serum_creatinine >  0.85
|   |   |--- class: 1
|--- ejection_fraction >  27.50
|   |--- serum_creatinine <= 1.45
|   |   |--- class: 0
|   |--- serum_creatinine >  1.45
|   |   |--- class: 1
```

Дерево читается сверху вниз. Из одиннадцати признаков алгоритм сам выбрал два — фракцию выброса и креатинин — и нашёл для них пороги. Получилось правило, которое можно произнести вслух:

- фракция выброса не выше 27,5% и креатинин выше 0,85 мг/дл — прогноз неблагоприятный;
- фракция выброса выше 27,5%, но креатинин выше 1,45 мг/дл — тоже неблагоприятный;
- в остальных случаях — благоприятный.

::: clinic Алгоритм переоткрыл клинику
Низкая фракция выброса и нарушенная функция почек — известные предикторы неблагоприятного исхода при сердечной недостаточности. Дерево ничего о кардиологии не знало: оно лишь искало разбиения, после которых группы становятся однороднее по исходу. Совпадение найденных правил с клиническим опытом — хороший знак. Обратная ситуация, когда модель опирается на что-то странное, — повод искать ошибку в данных.
:::

### Как дерево выбирает вопросы

На каждом шаге алгоритм перебирает все признаки и все возможные пороги и выбирает разбиение, после которого группы получаются наиболее «чистыми» — в идеале в одной только умершие, в другой только выжившие. Чистоту измеряют **индексом Джини**: он равен нулю, когда в группе пациенты одного класса, и максимален при соотношении пополам. Затем то же самое повторяется для каждой получившейся группы.

Отсюда свойства дерева: ему не нужно масштабирование, оно само находит пороги и взаимодействия признаков и равнодушно к выбросам.

## Глубина и переобучение

Если не остановить дерево, оно будет делить группы, пока в каждом листе не останутся пациенты одного класса.

```python
rows = []
for depth in [1, 2, 3, 5, 8, None]:
    t = DecisionTreeClassifier(max_depth=depth, random_state=0).fit(Xh_train, yh_train)
    rows.append({
        "глубина": depth or "без ограничения",
        "листьев": t.get_n_leaves(),
        "обучающая": round(t.score(Xh_train, yh_train), 3),
        "тестовая": round(t.score(Xh_test, yh_test), 3),
    })
print(pd.DataFrame(rows).to_string(index=False))
print("Точка отсчёта (всем «выживет»):", round(1 - yh_test.mean(), 3))
```

```output
        глубина  листьев  обучающая  тестовая
              1        2      0.766     0.667
              2        4      0.794     0.700
              3        8      0.847     0.733
              5       19      0.895     0.700
              8       34      0.957     0.644
без ограничения       48      1.000     0.633
Точка отсчёта (всем «выживет»): 0.678
```

Картина та же, что и у ближайших соседей. С ростом глубины качество на обучающей выборке приближается к 100%, а на тестовой сначала растёт, потом падает. Дерево без ограничений безошибочно на обучающих пациентах и при этом хуже, чем ответ «выживет» для каждого. Десятки листьев на двести пациентов — это уже не закономерности, а описание отдельных людей.

Глубину ограничивают параметрами `max_depth` (число уровней) и `min_samples_leaf` (минимум пациентов в листе).

У одиночного дерева есть ещё одно слабое место — **неустойчивость**. Стоит добавить или убрать несколько пациентов, и первый вопрос может смениться, а вместе с ним и всё дерево. С этим борются ансамбли, которым посвящён следующий теоретический урок.

## Сравнение методов

| | Логистическая регрессия | Ближайшие соседи | Дерево решений |
|---|---|---|---|
| Что выдаёт | вклад каждого фактора | исходы похожих пациентов | цепочку правил |
| Нужно масштабирование | желательно | обязательно | нет |
| Нелинейные связи | не улавливает сама | улавливает | улавливает |
| Объяснимость | высокая | низкая | высокая при малой глубине |
| Склонность к переобучению | низкая | высокая при малом k | высокая при большой глубине |

::: summary
- kNN предсказывает исход по k самым похожим пациентам; без масштабирования признаков он не работает.
- Дерево решений — последовательность вопросов с порогами, которые алгоритм находит сам, уменьшая неоднородность групп.
- Малое k и большая глубина дают идеальный результат на обучающей выборке и плохой на тестовой — это переобучение.
- Сложность модели ограничивают: числом соседей, глубиной дерева, минимальным размером листа.
- Неглубокое дерево легко объяснить, но оно неустойчиво к изменению данных.
:::
