Статистический тест отвечает на вопрос о группах: различается ли креатинин у выживших и умерших. Врачу у постели больного нужен ответ о конкретном человеке: каков риск у *этого* пациента? Машинное обучение — набор методов, которые строят такой ответ по данным. В этом уроке разберём, как формулируется задача и почему модель обязательно проверяют на пациентах, которых она не видела.

## Обучение с учителем

Мы работаем с ситуацией, когда для прошлых пациентов известен и набор признаков, и исход. Алгоритм ищет в этих данных закономерность, которая связывает одно с другим, чтобы применить её к новому пациенту с ещё неизвестным исходом. Это называют **обучением с учителем**: «учитель» — известные ответы.

По типу исхода различают две задачи.

- **Классификация** — исход категориальный: есть ИБС или нет, умрёт пациент за год или нет.
- **Регрессия** — исход количественный: длительность госпитализации, уровень гликированного гемоглобина через полгода.

Курс посвящён бинарной классификации, самой частой задаче в клинике. Хорошая модель классификации выдаёт не только ответ «да» или «нет», но и **вероятность**: «риск ИБС — 82%». С вероятностью врач может работать: сопоставить её с ценой ошибки и принять решение.

::: clinic Шкалы риска — это тоже модели
GRACE при остром коронарном синдроме, CHA₂DS₂-VASc при фибрилляции предсердий, SCORE2 для оценки сердечно-сосудистого риска — всё это результаты того же процесса: взяли данные тысяч пациентов с известным исходом, подобрали формулу, проверили на других пациентах. Разница с «искусственным интеллектом» — в сложности формулы, а не в принципе. И требования к проверке у них общие.
:::

## Обучающая и тестовая выборки

Модель можно подогнать под имеющиеся данные сколь угодно точно — вплоть до того, что она просто запомнит каждого пациента. Но ценность модели в том, как она работает на *новых* больных. Поэтому часть данных откладывают до обучения и используют только для итоговой оценки.

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split

hd = pd.read_csv("heart_disease.csv")
hd[["chol", "trestbps"]] = hd[["chol", "trestbps"]].replace(0, np.nan)
hd["target"] = (hd["num"] > 0).astype(int)

features = ["age", "sex", "cp", "trestbps", "chol", "thalach", "exang", "oldpeak"]
X, y = hd[features], hd["target"]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)
print("Обучающая выборка:", len(X_train), "тестовая:", len(X_test))
```

```output
Обучающая выборка: 690 тестовая: 230
```

Тестовая выборка играет роль экзамена: в неё нельзя «подглядывать» ни при обучении, ни при выборе признаков, ни при настройке параметров.

## Точка отсчёта

Прежде чем радоваться точности модели, нужно знать, чего можно добиться без неё. Самый простой ориентир — всегда предсказывать самый частый класс.

```python
from sklearn.dummy import DummyClassifier
from sklearn.metrics import accuracy_score

baseline = DummyClassifier(strategy="most_frequent").fit(X_train, y_train)
print("Доля верных ответов «у всех ИБС»:", round(accuracy_score(y_test, baseline.predict(X_test)), 3))
```

```output
Доля верных ответов «у всех ИБС»: 0.552
```

Модель, которая объявляет больным каждого, права в 55% случаев — просто потому, что больных в этих данных чуть больше половины. Точность 60% на таком фоне — почти ничего, а в популяции, где болезнь встречается у 2% людей, «точность 98%» даёт модель, не нашедшая ни одного больного. Число без точки отсчёта ничего не значит.

Второй ориентир — простое клиническое правило. В этих данных тип боли 4 («боли нет») неожиданно часто сочетается с подтверждённой ИБС. Вероятное объяснение — отбор: бессимптомного пациента направляют на ангиографию, только если на болезнь указывает что-то другое.

```python
rule_train = (X_train["cp"] == 4).astype(int)
rule_test = (X_test["cp"] == 4).astype(int)
print("Правило «cp = 4 → ИБС»:")
print("  обучающая:", round(accuracy_score(y_train, rule_train), 3))
print("  тестовая: ", round(accuracy_score(y_test, rule_test), 3))
```

```output
Правило «cp = 4 → ИБС»:
  обучающая: 0.745
  тестовая:  0.804
```

Одно правило по одному признаку заметно превосходит точку отсчёта. Любая более сложная модель должна доказать, что она лучше такого правила, — иначе её сложность ничем не оправдана.

## Переобучение

Теперь возьмём гибкий алгоритм — дерево решений без ограничения глубины. Подробно мы разберём его через два урока; пока важно лишь, что такое дерево способно выучить данные наизусть.

```python
from sklearn.tree import DecisionTreeClassifier

deep_tree = DecisionTreeClassifier(random_state=42).fit(X_train, y_train)
print("Глубокое дерево:")
print("  обучающая:", round(deep_tree.score(X_train, y_train), 3))
print("  тестовая: ", round(deep_tree.score(X_test, y_test), 3))
```

```output
Глубокое дерево:
  обучающая: 1.0
  тестовая:  0.717
```

На обучающей выборке дерево не ошибается ни разу. На тестовой оно хуже, чем правило из одной строки. Модель выучила не закономерности болезни, а случайные особенности конкретных пациентов — это называется **переобучением**.

Разрыв между качеством на обучающей и тестовой выборках — главный симптом переобучения. Ему способствуют:

- слишком гибкая модель;
- малое число пациентов;
- большое число признаков;
- многократная настройка «до лучшего результата» на одних и тех же данных.

Обратная проблема — **недообучение**: модель слишком проста, чтобы уловить закономерность, и плоха на обеих выборках. Искусство моделирования — в поиске сложности, которую выдерживают имеющиеся данные.

## От вопроса к модели

Технически обучить модель — дело нескольких строк. Трудное находится до и после.

1. **Клинический вопрос.** Какое решение должна поддержать модель: направить на ангиографию, усилить терапию, выписать?
2. **Момент прогноза.** Когда модель применяется и какие данные к этому моменту доступны?
3. **Данные.** Откуда они, кого представляют, как измерен исход.
4. **Разделение, подготовка, обучение.** То, чему посвящён этот раздел.
5. **Оценка.** Какие ошибки делает модель и чего они стоят — тема четвёртого раздела.
6. **Проверка в других условиях** и внедрение — пятый раздел.

::: warning Модель отвечает на тот вопрос, который задан данными
Наши пациенты — это люди, которых уже направили на коронарную ангиографию. Модель, обученная на них, оценивает вероятность ИБС *среди направленных*. Для случайного человека с улицы её оценки будут сильно завышены: в общей популяции болезнь встречается намного реже. Применять модель можно только к пациентам, похожим на тех, на ком она обучена.
:::

::: summary
- Обучение с учителем: по признакам и известным исходам прошлых пациентов строится правило для новых.
- Классификация предсказывает категорию и её вероятность, регрессия — число.
- Качество оценивают только на тестовой выборке, которую модель не видела.
- Любой результат сравнивают с точкой отсчёта: частым классом и простым клиническим правилом.
- Переобучение — модель запомнила обучающие данные; его признак — разрыв между качеством на обучающей и тестовой выборках.
- Модель применима к пациентам, похожим на обучающую выборку.
:::
