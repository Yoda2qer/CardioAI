Одно дерево решений понятно, но неустойчиво. Ансамбли превращают эту слабость в силу: вместо одного дерева строят сотни и объединяют их ответы — как на консилиуме, где мнение нескольких специалистов надёжнее мнения одного. Случайный лес и градиентный бустинг — самые популярные методы для табличных данных, и важно понимать не только как они работают, но и когда они действительно нужны.

## Насколько неустойчиво одно дерево

Проверим на данных о сердечной недостаточности. Двести раз составим новую выборку, случайно выбирая пациентов **с возвращением** (один и тот же человек может попасть в неё несколько раз, другой — ни разу), и каждый раз посмотрим, какой признак дерево поставит в корень.

```python
import numpy as np
import pandas as pd
from sklearn.tree import DecisionTreeClassifier

hf = pd.read_csv("heart_failure.csv")
features = [c for c in hf.columns if c not in ("time", "DEATH_EVENT")]
X, y = hf[features], hf["DEATH_EVENT"]

rng = np.random.default_rng(0)
roots = []
for _ in range(200):
    rows = rng.integers(0, len(X), size=len(X))
    stump = DecisionTreeClassifier(max_depth=1).fit(X.iloc[rows], y.iloc[rows])
    roots.append(features[stump.tree_.feature[0]])
print(pd.Series(roots).value_counts())
```

```output
serum_creatinine     118
ejection_fraction     66
age                   14
serum_sodium           2
Name: count, dtype: int64
```

Данные почти те же, а «главный вопрос» дерева меняется от выборки к выборке. Такой способ создания выборок называется **бутстрепом**, и на нём построен первый ансамбль.

## Случайный лес

Случайный лес обучает много глубоких деревьев и усредняет их ответы. Чтобы деревья получились разными, используют два источника случайности:

- каждое дерево обучается на своей бутстреп-выборке пациентов;
- при каждом разбиении дерево выбирает лучший признак не из всех, а из случайного подмножества.

Каждое отдельное дерево переобучено и ошибается по-своему. Но ошибки разных деревьев направлены в разные стороны и при усреднении гасят друг друга, а общая закономерность остаётся. Вероятность события — доля деревьев, проголосовавших «за».

Главные параметры: `n_estimators` — число деревьев (больше — стабильнее, но дольше; после нескольких сотен улучшение прекращается) и `max_depth` или `min_samples_leaf` — ограничение сложности каждого дерева.

## Градиентный бустинг

Бустинг тоже строит много деревьев, но не независимо, а **последовательно**. Первое маленькое дерево делает грубый прогноз. Второе обучается на его ошибках и поправляет их. Третье исправляет то, что осталось после двух первых, — и так сотни раз.

Каждое дерево добавляется с небольшим весом — **скоростью обучения** (`learning_rate`). Чем она меньше, тем осторожнее модель и тем больше деревьев ей нужно. В отличие от леса, бустинг можно «перекормить»: слишком много деревьев при высокой скорости обучения приводят к переобучению, поэтому его параметры требуют настройки.

На больших таблицах бустинг (библиотеки XGBoost, LightGBM, CatBoost) обычно показывает лучший результат среди всех методов.

## Сравнение на наших данных

Сравним четыре модели. Чтобы оценка не зависела от одного случайного разбиения, используем **перекрёстную проверку**: данные делят на пять частей, каждая по очереди служит тестовой, а четыре остальные — обучающей; результаты усредняют. Подробно этот метод и метрику AUC (0,5 — случайное угадывание, 1,0 — безошибочное разделение) разберём в следующем разделе.

```python
from sklearn.ensemble import GradientBoostingClassifier, RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

models = {
    "Дерево (глубина 3)": DecisionTreeClassifier(max_depth=3, random_state=42),
    "Логистическая регрессия": make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000)),
    "Случайный лес": RandomForestClassifier(n_estimators=200, random_state=42),
    "Градиентный бустинг": GradientBoostingClassifier(random_state=42),
}
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
for name, model in models.items():
    scores = cross_val_score(model, X, y, cv=cv, scoring="roc_auc")
    print(f"{name:24} AUC {scores.mean():.3f} ± {scores.std():.3f}")
```

```output
Дерево (глубина 3)       AUC 0.729 ± 0.075
Логистическая регрессия  AUC 0.772 ± 0.049
Случайный лес            AUC 0.775 ± 0.079
Градиентный бустинг      AUC 0.724 ± 0.079
```

Результат стоит внимательно прочитать.

Случайный лес заметно лучше одиночного дерева — усреднение работает. Но от логистической регрессии с её простой формулой он практически не отличается, а бустинг с параметрами по умолчанию оказался даже хуже. И посмотрите на число после знака «±» — это разброс между пятью частями данных. Он сопоставим с различиями между моделями: на 299 пациентах мы попросту не можем надёжно сказать, какая из них лучше.

::: clinic Сложность должна быть оправдана
Здесь всего 96 событий, а связи признаков с исходом в основном монотонны: чем выше креатинин, тем хуже. В такой ситуации гибкой модели нечего «находить» сверх того, что видит простая, зато есть что переобучить. Ансамбли выигрывают, когда данных много (тысячи событий), а связи сложны: пороги, взаимодействия, нелинейность. Начинайте с простой модели и переходите к сложной, только если она даёт ощутимый и проверенный выигрыш.
:::

## Что считает важным лес

Ансамбль из сотен деревьев нельзя прочитать как правило, но можно спросить, на какие признаки он опирается. Простейшая оценка — насколько в среднем разбиения по признаку уменьшали неоднородность групп.

```python fig=s3-forest-importance
import matplotlib.pyplot as plt

names = {
    "age": "Возраст", "anaemia": "Анемия", "creatinine_phosphokinase": "КФК",
    "diabetes": "Диабет", "ejection_fraction": "Фракция выброса",
    "high_blood_pressure": "Гипертензия", "platelets": "Тромбоциты",
    "serum_creatinine": "Креатинин", "serum_sodium": "Натрий", "sex": "Пол", "smoking": "Курение",
}
forest = RandomForestClassifier(n_estimators=500, random_state=42).fit(X, y)
importance = pd.Series(forest.feature_importances_, index=features).sort_values()

fig, ax = plt.subplots(figsize=(7.2, 4.4))
ax.barh([names[f] for f in importance.index], importance.values)
ax.set_xlabel("Важность признака (сумма по всем признакам равна 1)")
ax.set_title("На что опирается случайный лес")
ax.grid(axis="y", visible=False)
plt.show()
```

Креатинин, фракция выброса и возраст наверху — это согласуется со всем, что мы видели раньше. А вот КФК и тромбоциты настораживают: во втором разделе тесты не нашли различий по этим показателям между умершими и выжившими.

::: warning У этой оценки важности есть систематическая ошибка
Признак с большим числом разных значений даёт дереву больше возможных порогов, а значит, больше шансов случайно найти «удачное» разбиение. Поэтому непрерывные показатели вроде КФК и тромбоцитов получают завышенную важность, а бинарные — заниженную. Более честный способ, перестановочную важность, разберём в четвёртом разделе.
:::

## Что выбрать

| | Случайный лес | Градиентный бустинг |
|---|---|---|
| Деревья строятся | независимо, параллельно | последовательно, каждое исправляет предыдущие |
| Настройка | работает «из коробки» | требует подбора параметров |
| Риск переобучения | низкий | выше, растёт с числом деревьев |
| Качество на больших данных | хорошее | обычно лучшее |

Общее у обоих методов: им не нужно масштабирование, они сами находят нелинейности и взаимодействия — и оба платят за это объяснимостью. Врачу трудно доверять прогнозу, причину которого нельзя назвать, поэтому вопрос интерпретации моделей в медицине стоит особенно остро.

::: summary
- Одно дерево неустойчиво: небольшое изменение выборки меняет его структуру.
- Случайный лес усредняет много независимых деревьев, обученных на бутстреп-выборках со случайными подмножествами признаков.
- Градиентный бустинг строит деревья последовательно, каждое исправляет ошибки предыдущих; его нужно настраивать.
- На малых данных с простыми связями логистическая регрессия не уступает ансамблям.
- Различия между моделями сравнивают с разбросом оценок: разница внутри «±» ничего не доказывает.
- Встроенная важность признаков леса завышена для непрерывных показателей.
:::
